# Skills 目录

本目录存放自定义技能文件，用于扩展 AI 助手的能力。

## 技能列表

| 技能文件 | 技能名称 | 描述 |
|---------|---------|------|
| `test-project.md` | 测试模块 | 对指定模块进行系统性功能测试，输出 Playwright 网页版测试报告 |

## 技能格式

每个技能文件采用 Markdown 格式，包含以下结构：

```markdown
---
name: 技能名称
description: 技能描述
metadata:
  type: skill
---

# 技能标题

技能详细说明和使用指南...
```

## 使用方式

在对话中提及对应技能名称即可触发，例如：
- "测试登录模块"
- "对用户管理进行功能测试"

## 添加新技能

1. 在本目录创建 `.md` 文件
2. 按照上述格式编写技能内容
3. 文件名建议使用小写字母和连字符（如 `my-skill.md`）

## 技能设计原则

- **明确的前置条件**：执行前需确认的环境要求
- **分阶段工作流程**：将复杂任务拆解为可执行的步骤
- **标准化输出**：统一的输出格式便于阅读和复用
- **错误处理指南**：遇到问题时的调试方法
